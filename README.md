# Hantavirus: Global Disease Burden, Clinical Severity & Therapeutic Landscape

## Project Overview

A data-driven analysis of global Hantavirus disease burden,
clinical severity, and therapeutic development from 1993–2026.

The project examines confirmed cases, deaths, case fatality,
geographic distribution, viral load, disease severity, and
therapeutic development across 25 countries.

## Tools Used

- Python
- Power BI
- Excel

## Key Metrics

- Total Confirmed Cases: 599K
- Total Deaths: 17K
- Countries Affected: 25
- Study Period: 1993–2026
- Overall CFR: 2.83%

## Key Findings

- China recorded the highest number of confirmed cases.
- Europe (EURO) recorded 305,129 confirmed cases.
- The relationship between confirmed cases and deaths was
  strongly positive (r = 0.92).
- R² was 0.85 for the cases–deaths relationship.
- Viral-load categories showed differences in the proportion
  of severe and critical infections.
- The therapeutic landscape included vaccines, antivirals,
  monoclonal antibodies, diagnostics, immunotherapy, and
  supportive therapies.
